# 📊 Exploratory Data Analysis – Retail Sales

An Exploratory Data Analysis (EDA) project focused on analyzing **retail and e-commerce sales data** to identify sales trends, customer behaviour, product performance, and meaningful business insights using Python.

## 📌 Project Overview

Exploratory Data Analysis is an important step in the data analytics process. It helps understand the structure, patterns, relationships, and trends present in a dataset before applying advanced analytics or machine learning techniques.

In this project, a **retail sales dataset** is explored and analyzed using Python-based data analytics and visualization techniques.

The analysis focuses on understanding sales performance, identifying trends, and extracting useful insights from the available data.

## 🎯 Objectives

* Understand the structure and characteristics of the dataset
* Perform exploratory analysis on retail sales data
* Identify sales trends and patterns
* Analyze customer purchasing behaviour
* Examine product performance
* Study monthly sales patterns
* Create meaningful data visualizations
* Generate business-oriented insights from the dataset

## 🛠️ Technologies & Libraries

* **Python**
* **Pandas** – Data manipulation and analysis
* **NumPy** – Numerical operations
* **Matplotlib** – Data visualization
* **Seaborn** – Statistical visualization
* **Jupyter Notebook** – Analysis environment

## 📂 Dataset

The project uses a realistic **e-commerce/retail sales dataset** for performing exploratory analysis.

The dataset is included in the repository as:

```text
realistic_e_commerce_sales_data.csv
```

The dataset is analyzed to understand different aspects of sales performance and customer purchasing patterns.

## 🔍 Analysis Performed

### 1. Data Understanding

The dataset is initially examined to understand:

* Number of records and columns
* Data types
* Dataset structure
* Basic statistics
* Missing values
* Data consistency

### 2. Data Exploration

Different attributes of the dataset are explored to identify important patterns and relationships within the sales data.

### 3. Sales Trend Analysis

Sales are analyzed over time to identify:

* Monthly sales trends
* Changes in sales performance
* Periods of higher and lower sales
* Overall sales patterns

### 4. Customer Behaviour Analysis

The analysis explores customer purchasing behaviour to understand patterns in transactions and sales.

### 5. Product Performance

Products are analyzed to identify differences in sales performance and understand which products contribute to overall revenue.

### 6. Data Visualization

Different visualizations are created using Matplotlib and Seaborn to make patterns and trends easier to understand.

## ▶️ How to Run the Project
